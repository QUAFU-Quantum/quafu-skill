# 把结果做成好看的网页

目标：用户在自己的浏览器里打开一个**好看、能交互、能离线打开**的页面，一眼看懂这次运行。不是静态图片，不是 PDF。

## 先问风格

做之前问一句，给具体选项而不是问「你喜欢什么风格」：

> 结果页想要什么感觉？比如：① 深色仪表盘（像实验仪器面板）② 杂志排版（米白纸面、衬线标题）③ 极简白底 ④ 活泼彩色。不挑的话我就做一个深浅色自适应的简洁版。

用户说了喜欢的网站或品牌，就学它的**气质**（配色、留白、字重），不要照抄它的 logo 和文字。**不要默认套用 QUAFU 官网或云平台的视觉风格。** 没有偏好时，按公认好看的克制做法：一种强调色、充足留白、清楚的字号层级、数字用等宽对齐。

## 参考实现

`assets/pages/` 下两个自包含页面，`qf page <号> [--template ...]` 会把分析数据填进去并打开：

- `aurora.html`：仪器面板风格，跟随系统深浅色；
- `paper.html`：纸面排版风格，衬线大标题。

它们只是起点。改风格时改 `:root` 里的颜色变量和字体即可；要新图表（比如把几次运行放在一起对比、真机 vs 模拟器并排），照着里面的写法加。数据格式就是 `quafu-runs/<号>.analysis.json`，页面里通过 `window.QUAFU_DATA` 读取（模板中的占位符是 `/*QUAFU_DATA*/null`）。

## 硬要求

1. **一个 HTML 文件，离线能开**：CSS、JS、数据全内联；不引用 CDN、网络字体、外部图片。字体用系统字体栈（中文：PingFang SC / Microsoft YaHei / Noto Sans CJK SC 等）。
2. **用浏览器打开**：`qf page` 会自动打开；自己写的页面用 `python -c "import sys; sys.path.insert(0, r'<SKILL_DIR>/scripts'); import qf; qf.open_in_browser('page.html')"`（处理了 macOS、Windows、WSL、Linux）。
3. **图要能读数**：SVG 或 Canvas 画，鼠标悬停显示具体数值；有坐标刻度；理想和实测一眼区分（比如理想用空心框、实测用实心，图例写清楚）。不要彩虹色，一种强调色加一种中性色就够。
4. **布局**：整个内容区居中、有最大宽度（约 1000–1200px），正文、图、表**同宽对齐**；不要只把文字收窄贴在左边、右边大片空白。宽屏用两栏放「结论」和「运行信息」。手机宽度（约 390px）下不横向溢出。
5. **深浅色**：颜色写成 CSS 变量，在 `@media (prefers-color-scheme: dark)` 里给一套深色值；两套都要看着舒服。
6. **内容顺序**：标题（算法名 + 真机/模拟器）→ 一到三个大数字（最关键的结论）→ 主图 → 「这说明了什么」（人话，3–6 条）→ 运行信息（任务组号、目标、shots、时间）→ 折叠的原始数据。

## 交付前看一眼

用浏览器按桌面宽度和手机宽度各看一次（能截图就截图看）：文字和图右边缘对齐、左右留白相等、没有重叠的标签、深色模式下没有看不见的字。
