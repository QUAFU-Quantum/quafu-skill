# 上架 WorkBuddy 技能市场：分步指南

> 写于 2026-10-16，依据 WorkBuddy 开放平台文档（open.workbuddy.cn/docs）、帮助中心和开放平台网页里的界面文字；背景调研见 [国产平台接入调研.md](国产平台接入调研.md)。
> 标注：**已核实**＝官方文档写明；**界面文字**＝开放平台网页里的按钮和提示原文，具体在哪一步出现没有登录验证；**未核实**＝要登录后自己看。
> 注册、认证、提交都要本人操作，本指南只把材料和包备好。

## 先做什么

按顺序：

1. **定由谁上架**（第 1 节）。名称要用 QUAFU，最稳的是 QUAFU 商标权利人自己认证、自己上架。
2. **发邮件问商标材料**（第 2 节，草稿已写好）。等回复的同时可以做 3、4。
3. **本地先装一次**（第 3 节）：在 WorkBuddy 客户端里导入 zip，确认登录和网页能跑通。开放平台没有技能的测试环境，本地导入就是测试。
4. **认证 + 填开发者信息**（第 4 节）。开发者信息审核通过前不能创建技能。
5. **上传、填信息、提交审核**（第 5 节），预计 7 个工作日。
6. **审核通过后点「发布」**——不会自动上架。

## 1. 认证主体：个人还是企业

| | 个人 | 企业 / 其他组织 |
|---|---|---|
| 材料 | 大陆二代身份证、本人实名手机号、邮箱、手机刷脸（已核实） | 管理员先个人实名，再传营业执照（事业单位、社会团体走「其他组织机构认证」），然后三选一：法人刷脸、腾讯云企业实名账号授权、公众号或小程序企业实名授权（已核实） |
| 服务类目 | 只有「工具」「教育服务 → 教育信息展示」「商业服务」下的几项，**没有 IT 科技类**（已核实） | 有「商业服务 → 软件/建站/技术开发」等，无需资质（已核实） |
| 名称用 QUAFU | 要拿到商标权利人授权（开发者服务协议第 8.1 条：涉及第三方权利要事先取得授权，纠纷自负） | 认证主体就是商标权利人时，不需要额外授权 |

**要 Neo 确认的事**：QUAFU 商标的注册人是谁（推测是北京量子信息科学研究院，未核实）、注册了哪些类别（第 9 类软件、第 42 类技术服务等）。

- 如果由量子院上架：量子院是事业单位，走「其他组织机构认证」，需要事业单位法人证书和管理员的个人实名；要和院里管资质的人协调。
- 如果由 Neo 个人或别的公司上架：先备好商标注册证复印件和权利人盖章的授权书（写明授权在 WorkBuddy 开放平台以 QUAFU 名义发布技能），再等邮件回复确认要不要交、在哪一步交。

## 3. 不上架，先在本地用

1. 拿安装包：从 [Releases](https://github.com/QUAFU-Quantum/quafu-skill/releases/latest) 下载 `quafu.zip`，或在仓库里运行 `python3 tools/build_workbuddy.py`，生成 `dist/workbuddy/quafu.zip`。
2. 打开 WorkBuddy 客户端 → 左侧「技能」→「添加技能」→「上传技能」→ 拖入或「选择文件」选中 `quafu.zip`（已核实入口；zip 还是文件夹帮助页没写，按开放平台要求用 zip）。客户端会先做安全扫描，然后自动配置。
3. 在对话里说「用 QUAFU 做一个贝尔态实验」，看三件事：
   - 能不能装上 `quafu-sdk`（需要 Python 3.9+，WorkBuddy 用户可能没装 Python）；
   - 网页登录能不能拉起浏览器、授权后能不能拿到凭证（SDK 把登录态写到 `~/.quafu-sdk/`，WorkBuddy 只能访问授权的文件夹，可能被挡；不行就设 `QUAFU_CONFIG_DIR` 指到工作区里）；
   - 结果网页能不能在浏览器打开。
4. 跑不通的地方记下来，先改 skill、发新版本，再上架。

另一种本地装法（旁证，非官方）：把 `skills/quafu/` 复制到 `~/.workbuddy/skills/quafu/`，重启客户端。

## 4. 入驻开放平台

1. 打开 https://open.workbuddy.cn ，登录。
2. 首次进入会让你选认证方式：「个人认证」「企业认证」「其他组织机构认证」（界面文字）。按第 1 节的结论选，完成后点「进入开放平台」。
3. 左侧「设置 → 开发者信息」填写（已核实）：
   - 头像：512×512，JPG 或 PNG；
   - 昵称：2–20 字符、全平台唯一，不能含「官方、认证、独家、test、demo」，建议就写 `QUAFU`，和认证主体一致；
   - 简介：20–120 字，例如「QUAFU 量子计算云平台，提供量子模拟器与超导量子真机，面向科研与教育开放使用。」
   - 联系方式 1–5 项。
4. 提交开发者信息，等审核。没通过之前「创建」按钮不可用（界面文字：「开发者信息待完善，提交审核通过后方可创建／发布」）。

## 5. 上传技能并提交审核

先在仓库里打包，`--author` 写认证主体的名称（这是 frontmatter 里的 author，平台说明是「合作方名称」）：

```bash
python3 tools/build_workbuddy.py --author "认证主体名称"
```

脚本会校验：根目录是 `quafu/`、frontmatter 有 `description`、`description_zh`、`description_en`、`version`、`author`，值不带引号、冒号后有空格，zip 不超过 3MB。版本号取自 `.claude-plugin/plugin.json`。

然后在开放平台（以下按钮名都是界面文字，未登录验证）：

1. 左侧「资产管理 → 技能」→「创建」。
2. **配置技能**：「点击或拖拽上传代码包」，选 `quafu.zip`。平台自动解析并生成技能 ID。报「压缩包无法解析」「未找到 SKILL.md」时，检查 zip 根目录是不是 `quafu/`。
3. **确认信息**：
   - 分发范围勾「WorkBuddy 市场」（公开）；
   - 市场展示名称：`QUAFU`（包里的 `display_name`）；
   - 市场展示分类：选 1–3 个（可选值登录后才看得到，未核实；建议找「教育」「编程开发」一类）；
   - 版本号：自动读包里的 `1.0.0`；
   - 头像：512×512，≤500KB，JPG 或 PNG，用 QUAFU 标志；
   - 服务类目：企业选「商业服务 → 软件/建站/技术开发」；个人只能在「工具」「教育服务 → 教育信息展示」里挑；
   - 付费：选免费，不加密。
4. **提交审核**：核对后点「提交」。提示「已提交审核，预计 7 个工作日内出结果」。审核是安全扫描、AI 审核加人工抽检；结果发到认证时填的邮箱，平台内「通知中心」也能看到。
5. 被驳回：点「驳回原因」看备注，改好后「重新提交」。驳回后有一段整改期不能重传，同一个技能每天最多提交 3 次（界面文字）。
6. **通过后状态是「待发布」**，点「发布」→ 选「公开发布 - 全部用户可见」。状态变成「已发布」才算上架。

## 6. 上架之后

- **用户怎么找到**（已核实）：WorkBuddy 客户端左侧「专家·技能·连接器 → 技能 → 技能市场」，按分类浏览或搜索，点技能右上角的加号安装。搜索匹配哪些字段未公开，`description` 里已经写了 QUAFU、夸父、量子计算、量子线路等词。客户端 5.7.0 起可以把已发布的技能分享成链接。
- **看数据**：左侧「运营数据」，安装量、调用量、7 日留存，T+1 更新（已核实）。
- **更新版本**：
  1. 改 skill，把 `.claude-plugin/plugin.json` 的 `version` 加一，推送并发 GitHub Release；
  2. 重新运行 `python3 tools/build_workbuddy.py --author "认证主体名称"`；
  3. 开放平台在这个技能上点「更新版本」，上传新 zip，提交审核（界面文字有「更新版本」按钮；是否必须重新审核、版本号是否必须递增，未核实，按递增做）。
- 免费技能发布后暂时不能改成付费（已核实）。

## 仍要登录后才能确认的

- 市场展示分类和 frontmatter `category` 的可选值（包里先不写 `category`，在网页上选）；
- `description_zh`、`description_en`、`display_name` 的长度上限；
- 技能包的文件数、文件类型限制；
- 客户端「上传技能」是否也接受文件夹。
