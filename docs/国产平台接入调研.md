# WorkBuddy 与 Qoder 接入调研

> 查证日期：2026-10-16（所有出处都在当天查过）。只做了调研，没有注册、提交、上架或安装任何东西。
> 标注：**已核实**＝官方文档、官方协议或产品页原文写明；**推断**＝从官方材料推出，原文没直接写；**旁证**＝自媒体或社区文章，只作参考；**未知**＝没查到，要人工确认。

## 结论

**WorkBuddy**（腾讯，桌面端 AI 办公工作台，Windows / Mac，与 CodeBuddy 同一底座）直接支持 SKILL.md 格式的技能。两条路：

- **自己用**：客户端「技能 → 添加技能 → 上传技能」导入技能包（文件夹或 zip）。
- **公开上架**：在 WorkBuddy 开放平台（open.workbuddy.cn）完成个人或企业认证，上传技能 zip，选分类、服务类目、头像，提交审核；通过后出现在客户端技能市场，用户可按分类浏览或搜关键词。上架免费，也可开通「收入变现」，平台收技术服务费。

上架前要做两件事：

1. **定认证主体**：个人用二代身份证加人脸；企业用营业执照，再走法人刷脸 / 腾讯云企业实名 / 公众号或小程序企业实名三选一。
2. **改 frontmatter**：开放平台比 Claude Code 多要求 4 个必填字段 `description_zh`、`description_en`、`version`、`author`。

**用「QUAFU」做技能名称**：平台没有专门针对技能名称的商标审核条款公开；开发者服务协议写明涉及第三方权利的要事先取得权利人授权、纠纷自负。最稳的做法是**由 QUAFU 商标权利人自己做企业认证并上架**；用其他主体上架时，备好商标注册证复印件和权利人授权书（推断，需发邮件到 openworkbuddy@tencent.com 确认是否要交、在哪个环节交）。

**Qoder**（阿里）同样支持 SKILL.md，frontmatter 与 Claude Code 一致（`name` + `description`），**基本不用改**。接法：放进 `~/.qoder/skills/<名字>/`（用户级）或项目 `.qoder/skills/`；界面里上传 zip 或单个 SKILL.md；或 `npx skills add QUAFU-Quantum/quafu-skill -a qoder`。Qoder 有产品内技能市场（「提交到社区」），审核规则公开查不到。

### 1.3 开放平台流程

官方步骤：注册入驻 → 个人或企业认证 → 创建业务类型 → 完善基础信息和能力配置 → **测试环境调试** → 提交审核 → 发布上线 → 看运行数据、维护版本。可上架技能、专家、专家团、连接器、外部应用五类。（已核实，https://open.workbuddy.cn/docs/what-is-open-platform ）

**认证**（已核实，https://open.workbuddy.cn/docs/onboarding ）

- 个人：中国大陆二代身份证、本人实名手机号、邮箱、人脸识别；一张身份证全平台只能认证一个个人主体。
- 企业：管理员先个人实名，再上传营业执照，填对外展示的开发者昵称，最后三选一：法人刷脸、腾讯云企业实名账号授权、微信公众号或小程序企业实名授权。
- 个人认证能发技能、专家、连接器（旁证：https://news.qq.com/rain/a/20260902A0DOKE00 ）。

**开发者主页**（已核实，https://open.workbuddy.cn/docs/developer-profile ）：头像 512×512 JPG/PNG；昵称全平台唯一、2–20 字符，不得冒充官方，不得含「官方、认证、独家、test、demo」；简介 20–120 字；联系方式 1–5 项。原文：「昵称仅用于平台展示，不代表商标或品牌权利归属。昵称侵犯他人合法权益时，平台有权要求修改或收回」。

**技能包**（已核实，https://open.workbuddy.cn/docs/skill ）

```
{skill-name}/
├── SKILL.md        # 必须
├── references/     # 可选，SKILL.md 里用 @references/xxx.md 引用
├── scripts/        # 可选，AI 通过 Bash 工具执行
└── templates/      # 可选
```

| frontmatter 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 否 | 技能标识 |
| `description` | **是** | 用途与触发词 |
| `description_zh` / `description_en` | **是** | 简短中 / 英文介绍 |
| `version` | **是** | 版本号 |
| `author` | **是** | 合作方名称 |
| `allowed-tools`、`disable-model-invocation`、`user-invocable` | 否 | 工具白名单、禁止自动调用、菜单隐藏 |
| `display_name`、`display_name_en`、`category` | 官方模板里有 | — |

旁证：提交页自动解析大部分字段，手动选分类、服务类目、头像；YAML 冒号后要有空格，别用中文引号（https://news.qq.com/rain/a/20260902A0DOKE00 ）。

**服务类目**（已核实）：个人主体相关的只有「工具 → 信息查询 / 计算器」「教育服务 → 教育信息展示」（https://open.workbuddy.cn/docs/service-categories-individual ）；企业主体有「商业服务 → 软件/建站/技术开发」，无需资质（https://open.workbuddy.cn/docs/service-categories-enterprise ）。推断：QUAFU 用企业主体选「软件/建站/技术开发」最省事。

**审核**：平台按「届时有效的上架审核规范」审核，可要求改名称、标识、介绍（已核实，开发者服务协议第 4.4 条 https://rule.tencent.com/rule/202608300002 ）；审核规范全文**未知**；审核约 7 个工作日（旁证）；分安全扫描、AI 审核、人工抽检三道（旁证 https://cloud.tencent.com/developer/article/2740390 ）。

**用户怎么找到**：客户端「专家·技能·连接器 → 技能」进入市场，可按分类浏览、按关键词搜（已核实，https://open.workbuddy.cn/docs/skill ）。搜索匹配哪些字段**未知**，推断是名称加描述，所以「量子计算、量子云、QUAFU、夸父」要写进 `description` 和 `description_zh`。

**运营数据**：安装量、调用量、7 日留存，T+1 更新（已核实，https://open.workbuddy.cn/docs/operations-data ）。

**收费**：默认免费；开通收入变现要审核和微信签约，可设一次性或按月付费，付费技能加密并在云端运行，已发布的免费技能暂不能改付费（已核实，https://open.workbuddy.cn/docs/monetization ）；平台收技术服务费，费率**未知**（协议第 10.1 条）。

## 三、与本仓库格式的兼容性

| 项 | Claude Code / Codex | WorkBuddy 本地 | WorkBuddy 上架 | Qoder |
|---|---|---|---|---|
| 必填 frontmatter | `name`、`description` | 推断只要 `description` | 另加 `description_zh`、`description_en`、`version`、`author` | `name`、`description` |
| 包结构 | `skills/quafu/` | 文件夹或 zip | zip，根目录 `quafu/SKILL.md` | 文件夹、zip 或单个 SKILL.md |
| 执行本地 Python | 可以 | 可以，沙箱内、需用户批准、禁止写配置文件 | 同左；付费技能在云端跑 | 可以，按权限档确认 |
| 打开本地浏览器 | 可以 | **未知** | 同左 | **未知**，推断本地模式可以 |

要做的改动：

1. 主版本保持标准格式（`name: quafu` + `description`），Claude Code、Codex、OpenCode、Qoder 直接用。
2. WorkBuddy 上架包另外打：frontmatter 加 `display_name: QUAFU`、`description_zh`、`description_en`、`version`、`author`、`category`，以 `quafu/` 为根打 zip。这些字段放进主版本会不会让 Claude Code / Codex 报错，需实测（推断 Claude Code 忽略不认识的字段）。
3. 脚本路径：SKILL.md 里写「技能目录下的 `scripts/qf.py`」，不依赖任何平台专属变量。（本仓库已是这样。）
4. 最可能出问题的两处：SDK 把登录态写到 `~/.quafu-sdk/`，以及登录要拉起系统浏览器。WorkBuddy 只能访问授权工作区，需实测；不行时改用 `QUAFU_CONFIG_DIR` 指向工作区内目录。
5. WorkBuddy 用户多数不是程序员，可能没装 Python；SKILL.md 第 1 步已写缺 Python 时怎么办。
